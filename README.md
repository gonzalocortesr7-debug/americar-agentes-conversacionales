# Asistentes Virtuales · Levantamiento punta a punta · Americar

Levantamiento punta a punta del ecosistema de agentes conversacionales de Americar Chile (Venta, Postventa, Compra), con storytelling, indicadores, hallazgos y roadmap por agente.

**Período:** Ene 2025 – Abr 2026
**Publicado:** https://gonzalocortesr7-debug.github.io/americar-agentes-conversacionales/

## Contenido

- `index.html` — documento completo (single-page, sin dependencias).

## Stack

HTML + CSS + JS vanilla. Sin build, sin frameworks. Tipografías servidas por Google Fonts (Fraunces + IBM Plex Sans/Mono).

## Cómo verlo localmente

Abrir `index.html` en cualquier navegador, o servirlo con:

```bash
python3 -m http.server 8000
```
